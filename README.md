# Pesquisa de Opinião

## Descrição

Este projeto foi desenvolvido em Python para realizar uma pesquisa de opinião com clientes da empresa TudoWeb, com o objetivo de verificar o grau de satisfação com o atendimento prestado.

## Funcionamento

O programa solicita os seguintes dados de cada entrevistado:

- Nome
- Idade
- Opinião sobre o atendimento

As opções de opinião são:

1. EXCELENTE
2. BOM
3. RUIM

## Estruturas utilizadas

O programa utiliza:

- Estrutura de repetição `for` para realizar a pesquisa com 50 entrevistados.
- Estruturas de decisão `if` e `elif` para verificar a opinião dos entrevistados.

## Resultado

Ao final da pesquisa, o programa apresenta:

- Quantidade de respostas EXCELENTE
- Quantidade de respostas RUIM

## Teste

Foi realizado um teste com 10 entrevistados para verificar o funcionamento do programa.

O resultado do teste foi:

- 5 respostas EXCELENTE
- 3 respostas RUIM

## Arquivos

- `pesquisa_opiniao.py` — código do programa.
- `prints/codigos` — print do código.
- `prints/resultado` — print da execução e do resultado.
